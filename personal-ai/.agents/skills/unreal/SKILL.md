Đọc đường dẫn xuất trên phiếu và `checklist.md` trong thư mục skill này.

1. Chỉ dùng MCP `unreal-mcp` khi server đang bật.
2. Nhập file vào project đang mở.
3. Mở lại asset hoặc scene.
4. Ghi kết quả mở vào mục Giao file và phần scene vào mục Unreal.
5. Dừng. Không sửa file Blender.

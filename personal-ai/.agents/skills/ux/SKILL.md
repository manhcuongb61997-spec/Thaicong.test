Đọc phiếu đang mở và `checklist.md` trong thư mục skill này.

1. Viết các bước theo đúng thứ tự người dùng làm.
2. Với mỗi bước, ghi điều kiện trải nghiệm đạt.
3. Ghi vào mục UX trên phiếu.
4. Dừng. Màn hình, màu, khối và code thuộc phòng sau.

Đọc hướng hình đã được ký và `checklist.md` trong thư mục skill này.

1. Chỉ dùng MCP `blender-mcp` khi server đang bật.
2. Đọc scene hiện có trước khi sửa.
3. Dựng đúng hướng hình. Xuất file.
4. Ghi đường dẫn file Blender và đường dẫn xuất vào phiếu.
5. Dừng. Unreal thuộc phòng khác.
